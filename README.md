
# Lista Simplesmente Encadeada em C

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de Estrutura de Dados, com o objetivo de implementar uma lista simplesmente encadeada utilizando a linguagem C.

O sistema simula um cadastro de funcionários da empresa Renalf Mega Data.

## Funcionalidades

- Inclusão de funcionários
- Consulta por código
- Alteração de informações
- Remoção de funcionários
- Listagem de todos os registros

## Tecnologias utilizadas

- Linguagem C
- Estruturas de dados
- Structs e ponteiros
- Alocação dinâmica de memória

## Como executar

1. Baixe o arquivo main.c.
2. Abra em um compilador de linguagem C.
3. Compile e execute o programa.
4. Utilize o menu interativo para realizar as operações.

## Objetivo acadêmico

Praticar os conceitos de listas simplesmente encadeadas, manipulação de ponteiros e gerenciamento de memória.
